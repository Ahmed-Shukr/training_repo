# Advanced Views & Inheritance Presentation (BJT)

Chapter Four Beamer deck for **Odoo 17 Development Tutorials** by Ahmed Muhumed.

## Topics
- Transient models and wizard forms
- Abstract models
- Python and SQL constraints
- Extension (`_inherit`) and delegation (`_inherits`) inheritance
- XPath and view extension
- Smart / stats buttons
- Advanced views: Kanban, Pivot, Graph, Calendar, Activity, Gantt
- Navigation with menus and actions
